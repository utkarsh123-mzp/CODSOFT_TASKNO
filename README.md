# CodSoft Data Analytics Internship 🚀

**Author:** Utkarsh Upadhyay  
**Repository:** CODSOFT_TASKSNO  

This repository contains the tasks completed during the Data Analytics Virtual Internship at **CodSoft**. The internship focused on practical, project-based learning to transform theoretical knowledge into real-world data analytics expertise). 

## 📋 Tasks Completed

Out of the required 3 tasks for successful completion, I have successfully implemented all **5 tasks** using Python, Pandas, Matplotlib, Seaborn, and BeautifulSoup:

### TASK 1: Data Cleaning & Preprocessing
* Imported a messy dataset and inspected its structure.
* Identified and handled missing values, duplicate records, and inconsistent data entries.
* Prepared the data for analysis and exported the cleaned dataset to a new CSV file.

### TASK 2: Exploratory Data Analysis (EDA)
* Loaded the cleaned dataset and examined features using descriptive statistics.
* Identified trends, distributions, and detected outliers.
* Answered key business questions using summary statistics and basic visualizations.

### TASK 3: Data Visualization Dashboard
* Created meaningful and customized visualizations using Matplotlib and Seaborn.
* Designed a comprehensive dashboard featuring Bar charts, Line charts, Pie charts, Histograms, and Scatter plots to present insights clearly.

### TASK 4: Customer Data Analysis
* Analyzed customer data to understand purchasing behavior.
* Segmented customers based on age, location, and buying patterns.
* Created visual reports to identify the most valuable customer groups.

### TASK 5: Web Data Extraction & Analysis
* Scraped structured information (product details, prices, ratings) from publicly available websites using `BeautifulSoup` and `requests`.
* Cleaned and organized the collected data into a structured Pandas DataFrame.
* Exported the scraped results to a CSV file.

## 🛠️ Tools & Libraries Used
* **Language:** Python
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Web Scraping:** BeautifulSoup, Requests
* **Environment:** Jupyter Notebook / VS Code
